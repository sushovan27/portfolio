## Brand & Style

This design system navigates the tension between gallery-grade architectural minimalism and high-precision robotics instrumentation. It merges the austere, tactile restraint of a fine-art editorial monograph with the clinical telemetry of an advanced cybernetics control suite. The primary persona is an uncompromising technical designer, engineer, or research technologist operating at the frontier of spatial computing, robotics, and generative infrastructure.

### Design Principles
- **Monolithic Polarity:** Crisp interplay between bone-warm white studio light and dense, carbonized dark telemetry panels. Contrast is intentional, sharp, and structural rather than merely decorative.
- **Micro-Telemetry Precision:** Interfaces behave like high-tolerance optical readouts. Corner reticles, datum lines, monospace coordinates, and calibrated status pings ground every layout in functional logic.
- **Quiet Authority:** Typography commands attention via massive scale shifts—moving from whisper-weight 11px system monospacing directly to authoritative, negative-tracked display titles.
- **Engineered Glow:** Chromatic energy is severely disciplined. Luminescence is reserved strictly for active states, live sensors, and interactive focal points via a focused kinetic amber hue.

## Colors

The system uses an asymmetric chromatic structure built around a high-key architectural base (`#F3F2EF`) punctuated by monolithic carbon planes (`#111317`) and high-impact sensor accents (`#FF793D`).

### Color Roles & Distribution
- **Field Canvas (`#F3F2EF`):** The primary architectural environment. Evokes physical parchment, warm plaster, and controlled studio lighting.
- **Deep Monolith (`#111317`):** Reserved for technical instrumentation bays, code inspectors, and telemetry sidecars. Operates as an inverted micro-environment within the warm field.
- **Near-Black Core (`#17181B`):** Provides uncompromising typographic contrast and sharp silhouette clarity.
- **Optical Silver (`#D5D6D7`):** 1px structural framing, coordinate grids, and precision hair lines.
- **Sensor Amber (`#FF793D`):** Applied exclusively at pin-point scale for live status nodes, focus rings, cursor interactions, and active telemetry markers. Never used for large floods of background color.

## Typography

Typography establishes tension between human-scale editorial statements and machine instrumentation.

### Font Hierarchy & Roles
- **Headlines (Space Grotesk):** Brutal, geometric, and proportional. Large display scales are tightly tracked (`-0.04em`) to act as architectural anchors.
- **Body & Editorial (Inter):** Highly legible, neutral, and unobtrusive. Handles project narratives, descriptions, and long-form structural copy without distracting from visual artifacts.
- **HUD & Telemetry (JetBrains Mono):** Formatted in uppercase with extended letter spacing (`0.08em` to `0.12em`). Used strictly for system stamps, file sizes, coordinates, status markers, and categorical schema chips.

## Layout & Spacing

The layout is anchored by a rigid 8-point base unit, translating spatial density into mathematical balance.

### Grid Framework
- **Desktop (1440px+):** 12-column dynamic grid with `80px` (5rem) margins and `24px` (1.5rem) gutters. Grid lines can be optionally rendered via hairline borders (`#D5D6D7`) to emphasize the architectural scaffolding.
- **Tablet (768px - 1024px):** 8-column layout with `32px` margins and `16px` gutters. Sidecar modules drop below primary artifacts.
- **Mobile (390px - 767px):** 4-column layout with `20px` margins and `16px` gutters. Asymmetrical multi-column spreads collapse into linear vertical HUD tracks.

### Alignment Protocol
Align structural components strictly to column edges. Telemetry labels must align to the top-left or bottom-right coordinate edges of parent containers to reinforce machine-monitored boundaries.

## Elevation & Depth

Depth is established through physical surface transitions and atmospheric refraction rather than arbitrary drop shadows.

### Atmospheric Tiers
1. **Parchment Studio Floor (Ground Zero):** Static background layer (`#F3F2EF`). Completely flat, absorbing key light.
2. **Machined Monoliths (Inset Elevation):** High-density dark panels (`#111317`) resting directly on the ground plane, framed with a 1px border (`#D5D6D7` or `rgba(255, 255, 255, 0.12)`).
3. **Refractive Glass Pill (Floating HUD):** Suspended floating interface elements utilize a semi-permeable frosted material: `backdrop-filter: blur(16px)` with a fill of `rgba(243, 242, 239, 0.75)` and a micro-border `rgba(23, 24, 27, 0.08)`.
4. **Physical Subject Shadow:** Singular physical grounding shadow under focal renders: `box-shadow: 0 32px 64px -12px rgba(17, 19, 23, 0.14)`.
5. **Sensor Luminescence:** Active interactive pins emit localized amber diffusion: `box-shadow: 0 0 12px rgba(255, 121, 61, 0.45)`.

## Shapes

The shape vocabulary emphasizes technical calibration through sharp mechanical discipline, tempered by targeted pill forms for ergonomic navigation.

### Curvature Taxonomy
- **Corner Radii:** Structural components (cards, code panes, action modules) use strict, tight corners (`0.25rem` / `4px`) to preserve a milled, mechanical silhouette.
- **Instrument Panels:** Large hero containers use a soft architectural curve (`1.25rem` / `20px`) to prevent visual friction against viewport edges.
- **Floating HUD Pills:** Navigation capsules, filter triggers, and interactive toggles employ full radius (`9999px`) to distinguish fluid user actions from static mechanical readouts.
- **Reticle Brackets:** Crucial cards and technical frames use `4px` visual corner ticks (L-brackets) created using pseudo-elements, evoking an active camera or targeting HUD.

## Components

### Buttons
- **Primary Action:** Solid near-black container (`#17181B`), text in parchment (`#F3F2EF`). Features micro-notched L-bracket borders or a 2px amber (`#FF793D`) right-edge status notch. On hover: shifts upward by 2px with an amber outer rim glow.
- **Secondary HUD Action:** Transparent background with a 1px silver border (`#D5D6D7`), text in `#17181B`. Monospace index labels included before button label (e.g., `[01] INITIATE`).
- **Active State:** Border shifts instantly to sensor amber (`#FF793D`).

### Chips & Telemetry Tags
- **Production Status:** Solid light surface with a 1px border. Includes an active amber ping dot (`6px × 6px`) to indicate operational systems.
- **Exploratory / Learning Status:** Rendered with a dashed border (`border-style: dashed`, `#777A80`) with muted text to indicate experimental or in-progress status.
- **Categorical HUD Tags:** JetBrains Mono uppercase, enclosed in `[ ]` brackets with zero side padding.

### Navigation Pill
- Centered, floating glass capsule (`#F3F2EF` at 75% opacity, `blur(16px)`). Bound by a 1px perimeter line (`#D5D6D7`).
- Active link marked by a microscopic amber bar (`2px × 12px`) or subtle circular pip beneath the active label.

### Technical Input Fields
- Monolithic rectangular container with a 1px `#D5D6D7` border.
- Floating input label rendered in `mono-label-sm` (`#777A80`).
- Focus state: Replaces border with a crisp 1px `#FF793D` stroke and zero blur bloom. Caret colored `#FF793D`.

### Asymmetric Content Panels & Cards
- **Dark HUD Module:** Fill `#111317`, typography inverted to `#F3F2EF` and `#777A80`. Corners feature precise 1px silver reticles.
- **Project Showcase Rail:** Fixed-height preview frame with cross-fade transition. Interactive left-side list items shift 2px right on hover, triggering instantaneous coordinate readouts.
