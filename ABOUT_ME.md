## What not to say

Do not say:
- “Professional software engineer” unless later confirmed.
- “Cybersecurity expert” or “ethical hacker” as a credential.
- “AI engineer” as a professional title.
- “Expert in” a tool based only on its appearance in a repository or tech stack.
- That every visible GitHub repository is complete, deployed, or actively maintained.
- That a prototype is production-ready.
- Any invented GPA, ranking, certification, internship, award, client, user count, or impact metric.
